# 计网概述知识点
1. 计算机网络的产生与发展
计算机网络的发展大致经历了三个阶段：
1.第一阶段：从单个网络（ARPANET）向互联网演进。

2.第二阶段：构建了三级结构的互联网。

3.第三阶段：逐步形成全球范围的多层次ISP结构的互联网。

--------------------------------------------------------------------------------
2. 计算机网络的功能、组成与拓扑结构
2.1 网络的组成
1. 通信子网（Communication Subnet）
- 功能：负责全网的数据传输、转发、交换和通信控制。
- 组成：
- 通信设备：路由器、交换机、集线器、调制解调器等
- 通信链路：光纤、双绞线、无线信道等
- 通信协议：如TCP/IP、HTTP、FTP等
- 特点：关注“传输”，不涉及具体应用内容。
2. 资源子网（Resource Subnet）
- 功能：提供计算、存储和应用服务，实现资源共享。
- 组成：
- 主机（服务器、工作站、个人电脑、移动终端）
- 软件资源（操作系统、数据库、应用程序）
- 数据资源（文件、多媒体、网页内容等）
- 特点：面向“用户”和“应用”。
2.2 网络拓扑结构
网络拓扑结构是指用传输媒体将各种设备连接起来形成的物理布局，体现了网络中服务器、工作站的配置和连接方式。常见拓扑类型有：
- 星型
- 环型
- 总线型
- 树型
- 网状型
- 总线/星型

--------------------------------------------------------------------------------
3. 因特网的组成
- 边缘部分：端系统的通信方式（C/S、P2P）
- 服务模式：C/S（客户/服务器）
- 核心部分：三种交换方式
- 电路交换
- 报文交换
- 分组交换
分组交换要点
- 分组交换采用存储转发技术。
- 报文在发送前被划分为更小、等长的数据段，每个数据段加首部后构成一个分组。

- 分类（按作用范围）：
- 广域网 WAN

5. 计算机网络的性能指标
5.1 主要性能指标
1.速率：数据传输速率（比特率），单位bit/s
2.带宽：信道频带宽度/单位时间最大数据率
3.吞吐量：单位时间内通过网络的实际数据量
4.时延
- 发送时延 = 数据帧长度(bit) / 发送速率(bit/s)
- 传播时延 = 信道长度(m) / 传播速率(m/s)
- 处理时延、排队时延
5.时延带宽积 = 传播时延 × 带宽
6.往返时间RTT
- 有效数据率 = 数据长度 / (发送时间+RTT)
7.利用率

电磁波速率参考：
- 自由空间：3.0×10^5 km/s
- 铜线：2.3×10^5 km/s
- 光纤：2.0×10^5 km/s

8.2.2 信道极限容量
奈氏准则、香农公式、码元速率与信息速率的关系（课后习题p70,2-07,08,09、课堂习题ppt）
- 奈氏准则：Nmax = 2B（波特率，Baud）
- 多电平调制：Rmax = 2B × log2M（bps）
奈氏第一准则：理想低通信道中，最高码元速率为2B波特。
- 香农公式：C = B × log2(1 + S/N)（bps）
8.2.3 导引型传输媒体

11.1 广播信道的数据链路层

- 数据帧长度：64-1518字节

15.1 IP地址与相关协议
- IPv4：32位，默认子网掩码（A/B/C类），特殊地址如127.0.0.1，C类最大主机数等
- IPv6：128位
- MAC地址：数据链路层使用，物理唯一标识
- IP地址：网络层及以上使用，逻辑地址
ARP协议
- 功能：地址解析、维护ARP缓存表
ARP工作原理（同一局域网内）
1.发送ARP请求：主机A广播ARP请求包
2.接收与响应：目标主机B匹配后单播ARP响应包
3.更新缓存：主机A保存B的IP-MAC映射
4.数据通信：后续查表直接通信
IP数据报格式
- 首部固定部分长度：20字节
- TTL（生存时间）：数据包在网络中的寿命
--------------------------------------------------------------------------------
16.1 IP层分组转发流程
1.提取目的IP地址
2.查找主机路由或转发表
3.子网掩码与目的地址按位AND
4.默认路由转发或出错
16.2 ICMP协议
- 作用：辅助IP数据报转发，提高交付成功率
- 类别：差错报告报文、询问报文
- 应用：ping、tracert等
16.3 路由选择协议
- RIP协议：距离向量算法，特点：只与相邻路由器交换路由表，定时交换
- OSPF协议：链路状态算法，向本自治系统所有路由器发送信息

第五章 运输层
17.1 运输层作用与协议
- 主要协议：TCP、UDP
- 端口（port）：用于区分同一台计算机上的不同服务，常见端口如HTTP 80，FTP 21/20
UDP协议
- 无连接、不可靠、支持单播/多播/广播、简单，适合多媒体应用
TCP协议
- 面向连接、可靠传输、仅支持单播，适合Web、邮件、文件传输等
UDPTCP无连接面向连接不可靠可靠支持多播/广播仅单播简单复杂
连续ARQ原理
- 收到确认后窗口滑动
TCP滑动窗口原理
- 字节流上的窗口控制，分发送/接收方窗口
TCP连接建立（三次握手）
1.客户端发送SYN
2.服务器响应SYN-ACK
3.客户端确认ACK
TCP可靠传输
- 三次握手、数据传输与确认、快速重传、超时重传、流量控制、四次挥手断开
连接释放（四次挥手）
1.终止控制位FIN=1
2.对方确认
3.等待对方释放
4.最终确认

a.打开端口21，等待连接
